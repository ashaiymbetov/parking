- README (статус, запуск, таблица доказательств), раздел «Команды» в CLAUDE.md.

**Решения:** D-016…D-020.

**Проблемы / поправки агента:**
- Nest CLI 12 генерирует ESM + Vitest + oxlint вместо Jest; пакеты `@nestjs/config`/`@nestjs/typeorm` линии 12 — только ESM, Jest их не грузит. Агент перешёл на Nest 11 (CommonJS + Jest), записано в D-017.
- Первый запуск compose упал: `PORT`/`WORKER_POLL_MS` из env приходят строками, а без явной аннотации типа class-transformer их не приводил к числу. Локальные тесты этого не ловили (значения по умолчанию). Исправлено, добавлен юнит-тест (`fix: coerce numeric env vars from strings`).
- В песочнице агента `npm ci` внутри `docker build` не ходит в сеть без прокси, поэтому образы для проверки собирались из временных копий Dockerfile с прокси и CA песочницы (в репозиторий не попали), затем `docker compose up --no-build`. На обычной машине нужен только `docker compose up --build`.

**Тесты:** backend unit — 8/8, e2e — 3/3 (testcontainers и БД из compose). Ручная проверка compose с нуля: `/api/health` 200 напрямую и через nginx, фронтенд в headless Chromium показывает «API: ok, БД: up», Mailpit :8025 отвечает, миграция записана в `migrations`, worker тикает и выходит с кодом 0 по SIGTERM.

- Сид: 20 мест и тариф 250/120 — миграцией; демо-пользователи — идемпотентным `seedDemoData` (`SEED_DEMO=true` в compose, `npm run seed`). Пароли — scrypt.
- ARCHITECTURE §2 приведён к фактической схеме; README — статус и таблица доказательств; CLAUDE.md — команда сида.

**Решения:** D-021…D-024.

**Проблемы / поправки агента:**
- Тест поймал ошибку в миграции: `CHECK (… close_reason IN ('exit','forced'))` пропускал закрытый визит с `close_reason = NULL` (`NULL IN (…)` даёт NULL, а CHECK на NULL проходит). Добавлен явный `IS NOT NULL`.
- Тест «10 параллельных броней» был нестабилен: агент сначала требовал от всех проигравших код `23P01`, а PostgreSQL иногда отвечает `40P01 deadlock_detected` (отдельный эксперимент: 4 раунда из 20). Инвариант не нарушался ни разу. Тест исправлен (принимает оба кода, по-прежнему требует ровно одну бронь), правило для сервиса записано в D-024. Тест не ослаблялся до зелёного — сначала была найдена причина.
- После перезапуска сессии сменился порт прокси песочницы — сборка образов для проверки compose упала, временные Dockerfile пересозданы (в репозиторий не входят).

**Тесты:** unit — 22/22, e2e — 77/77 (testcontainers). Compose с нуля: 7 миграций применены, 20 мест, 1 тариф, 3 демо-пользователя; повторный старт backend — «0 users, 0 cars created»; `/api/health` 200.

**Дальше:** авторизация (JWT, роли) и профиль водителя.

**Проблемы / поправки агента:**
- Явный тест на границу тарифа внутри повторяющегося часа (осенний перевод) упал: реализация резала интервал только в моменты, когда часы «показывают» границу, а при переводе назад часы откатываются через границу, не показывая её. - После перезапуска сессии Docker не был запущен — e2e молча не выполнились в одном прогоне; запущены отдельно, 77/77.
- Проверка «тесты ловят ошибки»: 6 намеренных поломок реализации (цена по концу минуты, floor вместо ceil, без разреза на DST, `<=` на границе, фиксированный +6 ч вместо Luxon, игнор периода действия тарифа) — все пойманы.

**Тесты:** unit — 57/57 (из них тарификация 35, property-тесты по 100–500 прогонов), e2e — 77/77, typecheck, lint, build — чисто.
